# 유튜브 시청 기록 내보내기 안내 (사용자용)

- 작성일: 2026-10-24 (실제 내보내기 과정을 따라가며 기록)
- 상태: 1~3단계 확인 완료, 4~5단계는 파일을 받고 서비스가 완성된 뒤 보완
- 쓰임: 서비스 소개 페이지, 앱 안의 안내 화면(`/guide/takeout` 후보), 친구에게 보내는 안내

> "내 음악 결"은 유튜브에서 들은 음악 기록으로 취향을 분석합니다. 기록 파일은 Google이 직접 만들어 주는 **Google 테이크아웃**으로 받습니다.

**걸리는 시간**

| 단계 | 시간 |
|---|---|
| 내보내기 요청 | 약 5분 |
| Google이 파일을 만드는 시간 | 보통 몇 분~몇 시간, 길면 하루 이틀 |
| 내려받아 서비스에 올리기 | 약 1분 |

---

## 시작하기 전에

- **평소 유튜브를 보는 Google 계정**으로 로그인되어 있는지 확인합니다. 다른 계정으로 내보내면 기록이 거의 비어 있습니다.
- 휴대폰, TV, YouTube Music 앱에서 같은 계정으로 들은 것도 모두 포함됩니다.

## 1단계. 기록이 얼마나 남아 있는지 확인 (선택)

1. https://myactivity.google.com/product/youtube 에 들어갑니다.
2. 위쪽 두 항목을 봅니다.

| 항목 | 이렇게 보이면 |
|---|---|
| YouTube 기록 저장 | "저장 중"이어야 기록이 쌓여 있습니다 |
| 자동 삭제 | "중지됨"이면 처음부터 남아 있음. "36개월보다 오래된 활동 삭제"면 최근 3년 치만 있음 |

최근 몇 년 치만 있어도 분석에는 충분합니다.

`(스크린샷 자리: YouTube 기록 화면의 "저장 중 / 자동 삭제" 두 줄)`

## 2단계. 내보내기 요청 (약 5분)

1. https://takeout.google.com 에 들어갑니다.
2. 목록 위의 **"모두 선택 해제"**를 누릅니다.
3. 목록을 내려 **"YouTube 및 YouTube Music"**만 체크합니다. 위쪽에 "65개 중 1개 선택됨"처럼 보이면 맞습니다.

   `(스크린샷 자리: YouTube 및 YouTube Music만 체크된 화면)`

4. 그 항목 아래 **"모든 YouTube 데이터 포함됨"**을 누릅니다.
   - 창 위의 체크를 모두 해제하고 **"시청 기록"**만 체크합니다.
   - **확인**을 누르면 버튼이 **"유형 1개 선택됨"**으로 바뀝니다.
   - 이걸 하지 않으면 올린 동영상까지 들어가 파일이 매우 커질 수 있습니다.

   `(스크린샷 자리: "시청 기록"만 체크된 창)`

5. 왼쪽 **"여러 형식"**을 누릅니다.
   - 목록에서 **"기록"** 항목의 형식을 **HTML에서 JSON으로** 바꿉니다. 다른 항목은 그대로 둡니다.
   - **확인**을 누릅니다.

   `(스크린샷 자리: "기록 — JSON"으로 바뀐 창)`

6. **"다음 단계"**를 누르고, 아래처럼 되어 있는지 확인합니다. 기본값 그대로면 바꿀 것이 없습니다.

| 항목 | 값 |
|---|---|
| 이전 방식 | 이메일을 통해 다운로드 링크 전송 |
| 실행빈도 | 한 번만 내보내기 |
| 파일 형식 | .zip |
| 파일 크기 | 2GB (시청 기록만이라 훨씬 작게 한 파일로 옴) |

7. 아래쪽 **"내보내기 생성"**을 누릅니다.
8. "Google에서 YouTube 및 YouTube Music의 데이터 사본을 생성하고 있습니다" 화면이 나오면 요청이 끝난 것입니다.

## 3단계. 메일 기다리기

메일이 **두 번** 옵니다.

| 메일 | 내용 | 할 일 |
|---|---|---|
| ① "Google 데이터 보관처리 요청됨" | 요청을 받았다는 확인 메일. 다운로드 링크가 아님 | 없음. "활동 확인" 버튼은 본인이 요청하지 않았을 때를 위한 것이라 누르지 않아도 됨 |
| ② "Google 데이터 다운로드 가능" | 파일이 준비되었다는 메일. 내려받을 수 있는 마감 날짜가 적혀 있음 | **"Google 테이크아웃 요청 관리"** 버튼을 눌러 4단계로 |

- 진행 상황은 https://takeout.google.com 의 **"내보내기 관리"**에서 볼 수 있습니다.
- **다운로드 링크는 1주일 동안만 유효합니다.** 지나면 2단계부터 다시 요청합니다.
- 실제 예: 시청 기록만 요청했을 때 요청(18:44)부터 다운로드 메일(18:50)까지 **약 6분** 걸렸습니다(2026-10-24).

## 4단계. 내려받기와 파일 찾기

1. 다운로드 메일의 **"Google 테이크아웃 요청 관리"** → 목록에서 **다운로드**를 누릅니다. 본인 확인으로 Google 비밀번호를 다시 물을 수 있습니다.
2. 내려받은 .zip 파일의 압축을 풉니다.
3. 아래 위치에 파일이 있습니다. 폴더와 파일 이름은 **Google 언어 설정을 따릅니다.**

| 언어 설정 | 올릴 파일 |
|---|---|
| 한국어 | `Takeout/YouTube 및 YouTube Music/시청 기록/시청 기록.json` |
| 영어 | `Takeout/YouTube and YouTube Music/history/watch-history.json` (영어 이름은 공개 자료 기준, 직접 확인 전) |

- 같은 폴더에 **`검색 기록.json`**(영어: `search-history.json`)도 함께 들어 있습니다. 이 파일은 **올리지 않습니다.** 서비스도 받지 않습니다.
- 실제 예(2026-10-24, 한국어 설정): `시청 기록.json` 약 15MB, 3만여 건.

## 5단계. 서비스에 올리기 (서비스 완성 후 보완 예정)

1. "내 음악 결"의 **"청취 기록으로 분석"**을 누릅니다.
2. 4단계의 시청 기록 파일(`시청 기록.json` 또는 `watch-history.json`)을 고릅니다.
3. 브라우저가 파일을 읽어 **음악만 골라내고**, "전체 N건 중 음악 M건"을 보여 줍니다.
4. **올리기**를 누르면 분석이 시작되고, 끝나면 결과 링크가 나옵니다.

## 개인정보는 이렇게 다룹니다

- **파일 전체를 서버로 보내지 않습니다.** 음악을 골라내는 일은 사용자의 브라우저 안에서 하고, 음악 항목만 서버로 보냅니다. 일반 영상 제목은 보내지 않습니다.
- 올린 청취 기록 원본은 **7일**, 분석 결과는 **30일** 뒤 자동으로 지웁니다. 결과 화면의 **삭제** 버튼으로 바로 지울 수도 있습니다.
- 회원 가입이 없습니다. 결과는 무작위 링크로만 열립니다.

## 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 기록이 적게 나와요 | 자동 삭제가 켜져 있거나, 기록 저장을 꺼 둔 기간이 있거나, 다른 계정으로 내보냈을 수 있습니다. 1단계 화면을 확인하세요 |
| 유튜브 기록 화면에는 오래된 기록이 있는데 파일에는 최근 것만 있어요 | Google 테이크아웃은 최근 기록부터 일부만 내보내는 경우가 있고, **받을 때마다 양이 다를 수 있습니다**(실제 예: 같은 계정에서 한 번은 7개월 치 3만여 건, 다시 받았을 때는 2개월 반 치 1만여 건). 기간이 짧게 나오면 다시 내보내 보고 더 긴 파일을 올리세요. 결과 화면에 실제 분석 기간이 표시됩니다 |
| 다운로드 메일이 안 와요 | "내보내기 관리"에서 진행 중인지 보고, 스팸함도 확인하세요. 길면 하루 이틀 걸립니다 |
| 링크가 만료됐어요 | 2단계부터 다시 요청하세요 |
| 파일이 HTML이에요 | 2단계 5번에서 형식을 JSON으로 바꾸지 않은 경우입니다. 다시 요청하세요 |

## 작성 메모 (소개 페이지를 만들 때)

- 스크린샷은 **개인정보가 보이지 않는 계정·브라우저**로 다시 찍어 넣는다. 지금 따라가며 찍은 화면에는 이메일 주소, 다른 탭, 실제 시청 목록이 보여서 쓰지 않는다.
- 찍을 화면: 1단계 기록 설정, 2단계 3·4·5·6번, 진행 상황 화면, 3단계 두 메일, 4단계 폴더 구조, 5단계 업로드 미리보기.
- 4단계의 한국어 경로·이름은 2026-10-24 실제 파일로 확인했다. 영어 이름은 영어 설정 계정으로 한 번 확인해 표를 고친다.
