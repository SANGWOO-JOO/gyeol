> 이 문서는 {시행일}부터 적용돼요. gyeol(이하 "서비스")은 회원가입 없이 쓰는 서비스라, 꼭 필요한 정보만 받고 정해진 기간이 지나면 지워요.

## 1. 한눈에 보기

- **청취 분석:** 유튜브 기록 파일은 브라우저 안에서 먼저 걸러, 음악으로 보이는 기록만 서버로 보내요. 올린 기록은 7일 뒤 지워지고, 결과 화면에서 바로 지울 수도 있어요.
- **음악 방:** 닉네임과 4자리 암호(암호화해서 저장), 방장 이메일(인증 코드용)을 받아요. 방을 지우거나 1년 동안 쓰지 않으면 7일 뒤 모두 지워져요.
- **광고·분석 도구:** 쓰지 않아요. 정보를 팔거나 광고에 쓰지 않아요.

## 3. YouTube API 서비스 이용

서비스는 YouTube API 서비스를 사용해요. 서비스를 이용하면 [YouTube 서비스 약관](https://www.youtube.com/t/terms)에 동의하는 것으로 보며, YouTube 데이터는 [Google 개인정보처리방침](https://policies.google.com/privacy)에 따라서도 처리돼요.

- **보내는 것:** 음악인지 확인할 영상의 ID만 보내고, 받는 정보는 영상 분류(카테고리)뿐이에요.
- **보관:** 받은 분류 결과는 29일 동안만 보관하고 지워요. 업로드에서 온 영상 제목·채널을 정리한 공용 판정 기록도 29일 안에 지워요.
- **계산 방식:** 음악인지 판정한 결과와 분석·추천 수치는 YouTube가 제공한 통계가 아니라, 이용자가 올린 기록으로 서비스가 직접 계산한 값이에요.
- **삭제:** 결과 화면의 **지금 삭제**를 누르면 올린 기록과 결과가 바로 지워져요. 연락처로 삭제를 요청하면 7일 안에 처리해요. 서비스에서 지워도 YouTube·Google 계정의 시청 기록에는 영향이 없어요. 시청 기록 자체는 Google 내 활동에서 관리할 수 있어요.
- **권한:** 서비스는 Google 계정에 로그인하거나 접근 권한을 받지 않아요. 혹시 연결한 권한이 있다면 [Google 보안 설정](https://security.google.com/settings/security/permissions)에서 언제든 끊을 수 있어요.

## 4. 보관 기간과 파기

- 위 표의 기간이 지나면 매일 새벽 정리 작업이 지워요. 저장소 파일을 먼저 지우고 데이터베이스 행을 지워요.
- 결과 화면의 **지금 삭제**를 누르면 올린 파일, 청취 기록, 결과가 바로 지워져요.
- 방장이 방을 지우거나 운영자가 숨기면 7일 뒤 방, 멤버, 노래, 이메일, 선물 그림이 함께 지워져요. 그 7일 동안은 되돌릴 수 있어요.
- 마지막으로 쓴 지 1년이 지난 방은 자동으로 숨기고, 7일 뒤 같은 방법으로 지워요.
- 메일 발송 기록과 관리자 접속 IP는 90일이 지나면 지워요.
- 관리 작업 기록은 사고 조사를 위해 1년 보관하되, 방이 지워질 때 IP와 닉네임은 빼요.
- 데이터베이스 백업은 최대 14일 보관돼, 지운 정보도 그 기간 동안 백업에 남을 수 있어요. 백업은 복구 말고는 쓰지 않아요.

## 6. 이용자의 권리

- 결과 화면에서 청취 기록을 바로 지울 수 있어요.
- 방에서는 내 정보 판에서 닉네임을 바꾸거나 이 기기에서 나갈 수 있고, 방장은 방 설정에서 멤버를 내보내거나 방을 지울 수 있어요.
- 그 밖에 열람, 정정, 삭제, 처리 정지를 원하면 아래 연락처로 알려 주세요. 회원 계정이 없으므로 결과 링크나 방 이름·닉네임으로 본인을 확인해요.
- 만 14세 미만은 서비스를 이용할 수 없어요. 그런 이용이 확인되면 관련 정보를 바로 지워요.

## 7. 안전성 확보 조치

- 암호, 인증 코드는 일방향 암호화(BCrypt), 결과 링크·방 열쇠는 해시값으로만 저장해요.
- 저장소는 비공개이고 서버 쪽 암호화를 켜 두었어요.
- 관리자 화면은 비밀번호와 일회용 코드로 들어가고, 관리자는 방장 이메일을 가린 채로만 봐요. 관리 작업은 기록으로 남아요.
- 로그에는 이메일을 가려서 남겨요.

## 8. 쿠키와 기기 저장소

방에 다시 들어오도록 방 열쇠를 쿠키(gyeol_room, 해당 방 주소에서만)와 기기의 브라우저 저장소(localStorage)에 둬요. 둘 다 180일이 지나면 쓰지 않아요. 브라우저 저장소의 열쇠는 저장한 지 180일이 지나면 다음에 열 때 기기에서 지워요. 화면 설정과 최근 검색어도 기기에만 둬요. 브라우저 설정에서 지우면 되고, 지운 뒤에는 닉네임과 4자리 암호로 다시 들어오면 돼요. 광고·추적 쿠키는 쓰지 않아요.
